RaceOpt / Field notes

From data to decisions

RaceOpt processes F1 race strategy from real lap telemetry throughout the workflow — from raw data collection, training the lap-time prediction model, simulating the full grid, to finding faster strategic alternatives

Scope of the tool

RaceOpt is an independent analysis platform created for educational purposes. It is not an official product and is not affiliated with, endorsed by, or associated with Formula 1, FIA, any racing teams, or related trademarks. All figures come from a statistical model trained on historical data and are not real race predictions. It also does not model future car development, live rival strategy, or driver decisions mid-race.

01

Data — FastF1 lap telemetry

Source of all data

All figures on this website begin with FastF1 — the official F1 timing and telemetry library that converts the data into a driver-by-driver lap-by-lap dataset. This includes lap times, sector times, tyre compound, tyre age, track status, weather, and actual starting grid position. Data is cached on disk after the first fetch (see the cache/ folder) so the page does not need to send repeated requests.

02

Model — Random Forest Regressor

Predict lap times

The RandomForestRegressor model is trained on real lap telemetry to predict lap time from features such as tyre age, compound, estimated fuel remaining, and the current stint. It is validated by comparing predicted and real times for drivers outside the training set. See the full hyperparameters and features in the Model Report

03

Simulation — full-grid model

Strategy Lab

Once a strategy is defined (tyre + pit lap), the system generates the feature set for every lap, predicts each lap time with the model, adds a pace offset calibrated to the real driver, and includes the estimated pit loss for that circuit. It then combines the results for the full grid to rank drivers and calculate win probability.

04

Optimization — search for faster strategies

Strategy Analysis

Grid search evaluates every feasible tyre and pit-lap combination for the circuit, compares the total time with the real strategy used by the driver, and classifies faster options as undercut or overcut based on the pit lap relative to the baseline. See the details and terminology in the Strategy Analysis
